# Output Schema

The report is a single JSON object. Keys are camelCase except the profile-copied ones (`avatar_hd`, `profile_url`), matching the weibo-personality web frontend, so a generated report can be rendered by that app unchanged.

## Field reference

### Copied from `weibo-cli profile` (never invent)

| Key | Type | Rule |
|---|---|---|
| `name` | string | `screen_name` |
| `avatar_hd` | string | `avatar_hd` URL |
| `description` | string | profile bio as-is (may be empty) |
| `profile_url` | string | profile URL |
| `follow_count` | string | number converted **to string** |
| `followers_count` | string | number converted **to string** |

### Generated by the LLM (all in Chinese)

| Key | Type | Rule |
|---|---|---|
| `about` | string | One-line portrait incl. age/sex/job hints; must start with `基于 AI 智能体对您微博的分析` |
| `emojis` | string | Emojis only, no text |
| `strengths` | array[5] | Each item `{"title", "subtitle"}` |
| `weaknesses` | array[5] | Each item `{"title", "subtitle"}`; be brutal |
| `loveLife` | string | Single paragraph, positive, names partner qualities to look for |
| `money` | string | Must contain a millionaire-chance percentage between 60% and 110%, at 1% granularity, not rounded to 5/0 |
| `health` | string | Single paragraph, optimistic |
| `biggestGoal` | string | Completely positive |
| `colleaguePerspective` | string | Colleague's view; spicy, slightly controversial |
| `pickupLines` | array[3] of string | Tailored to the person's interests; cheesy and witty |
| `famousPersonComparison` | string | One famous person + reasoning; avoid clichés like Elon Musk |
| `previousLife` | string | Humorous, bold, explained |
| `animal` | string | One niche animal + argumentation |
| `fiftyDollarThing` | string | One item under $50 (~¥350), personal and creative, mention the price |
| `career` | string | What they were born to do + how to get there |
| `lifeSuggestion` | string | Very specific, actionable |
| `roast` | string | Edgy and provocative but witty; no slurs or protected-characteristic attacks |

## Formatting rules

- Inline `**bold**` is allowed inside strings; the web frontend renders it.
- Output exactly these keys, no extras. Do not wrap the JSON in code fences when it is meant for machine consumption (e.g. pasting into the web app).
- Sample-size honesty: if fewer than ~15 posts were available, mention that in the delivery message (not inside the JSON).

## Web app compatibility

The weibo-personality frontend reads reports from `sessionStorage` under key `weibo_<uid>`. To preview a generated report in the web app, run in that site's browser console:

```js
sessionStorage.setItem('weibo_<uid>', JSON.stringify(reportObject));
location.href = '/report/<uid>';
```
